# FDE Learning Roadmap

## Phase 1: Agent Fundamentals

**Goal:** Understand how an agent decides what action to take and how that action gets executed.

Topics:
- Agent execution flow
- Action selection
- Tool registration
- Tool lookup and execution
- Passing arguments to functions
- Handling tool results

Progress: Initial agent labs implemented.

## Phase 2: Tool Orchestration and Validation

**Goal:** Make tool execution predictable and validate the data flowing through the system.

Topics:
- Dynamic tool selection
- Keyword argument passing
- Input validation
- Result validation
- Error handling
- Automated testing

Progress: Agent Lab 4 and its test suite implemented.

## Phase 3: Agent Memory

**Goal:** Understand how agents retain and retrieve useful information.

Topics:
- Working memory
- Memory storage and retrieval
- Context management
- Memory validation
- Persistent memory
- Memory testing

Progress: Initial memory lab and its test suite implemented.

## Phase 4: Reliable Agent Architecture

**Goal:** Move from individual learning exercises toward a coherent agent framework.

Planned topics:
- Tool schemas
- Typed inputs and outputs
- Structured errors
- Execution limits
- Tool permissions
- Retry policies
- Observability
- Security boundaries

## Phase 5: Production Engineering

**Goal:** Build systems that can be deployed, monitored, and maintained.

Planned topics:
- Logging and tracing
- Metrics
- API integration
- Configuration management
- Docker
- CI/CD
- Deployment
- Failure recovery

## Phase 6: End-to-End FDE Project

**Goal:** Demonstrate the ability to take a real problem from discovery through implementation and deployment.

Planned deliverables:
- Problem definition
- Architecture document
- Working agentic system
- Automated tests
- Deployment instructions
- Observability
- Security considerations
- Engineering trade-offs
- Demonstration and technical write-up

## Development Principle

Every major capability should have an implementation, tests, documentation, and a clear explanation of its engineering trade-offs.
